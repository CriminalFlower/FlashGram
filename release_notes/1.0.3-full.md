# FlashGram 1.0.3

Большое обновление FlashGram: собственная верификация, бейджи организаций,
NFT-подарки через официальные магазины, анонимный номер, защита сервера и
вход без обязательной почты.

FlashGram — неофициальный клиент на основе Telegram Desktop. Всё, что
помечено как FlashGram, работает только внутри FlashGram и не является
данными или верификацией Telegram.

## новое

### верификация FlashGram
- отдельный экран "FlashGram Verification" в главном меню, в FlashGram Hub и в блоке FlashGram профиля
- вкладки канал / личный / бот с анимированным переключением
- живое превью: макет профиля с вашей аватаркой, именем и бейджем FG ✓
- уровни бейджа: Verified, Creator, Business, Developer; Partner и Support выдаёт только команда FlashGram
- карточка "специальный план": 1 год, Test Access, бесплатно на время теста
- блок требований с живыми статусами: профиль заполнен, аккаунт связан с сервером, нет нарушений, соблюдены правила
- перед отправкой заявки показывается превью бейджа и можно выбрать, показывать ли профиль публично
- статус заявки в карточке: на рассмотрении, одобрена, отклонена с причиной, отозвана
- собственный бейдж FG ✓ — не официальная галочка Telegram и не выдаётся как верификация Telegram

### топ и каталог
- нижняя навигация экрана верификации: верификация, топ, каталог, профиль
- топ публичных профилей FlashGram Verified с местами
- каталог по категориям: авторы, бизнес, боты, каналы, разработчики
- показываются только профили, которые сами включили публичность; приватные данные и FlashGram ID не показываются
- переключатель "показывать в топе и каталоге" на странице профиля

### бейджи организаций Major и Hold
- отдельный блок в профиле: "этот пользователь верифицирован в FlashGram организацией «Major»" или «Hold»
- у бейджа есть дата выдачи, срок действия и кто выдал; истёкшие бейджи скрываются автоматически
- эмблема M / H с меткой FG и подписью "бейдж FlashGram", отдельно от официальной верификации Telegram
- бейджи видны и в чужих профилях, если их выдал администратор FlashGram

### панель администратора
- список заявок: ожидают, одобрены, отклонены
- карточка заявки: имя, username, FlashGram ID, тип, уровень, дата, статус
- одобрение, отклонение и отзыв с причиной; всё выполняется только на сервере
- выдача и отзыв Major / Hold по FlashGram ID со сроком действия и своим описанием

### NFT-подарки
- раздел "NFT-подарки" в главном меню, FlashGram Hub и профиле
- кнопка "открыть официальный магазин" открывает магазин подарков Telegram с ценами Telegram
- переход на Fragment для коллекционных username, номеров и подарков
- подборка FlashGram: карточки лотов с редкостью и ценой, покупка только по официальным ссылкам t.me/nft и fragment.com
- без официальной ссылки кнопка неактивна ("скоро"); FlashGram не продаёт подарки и не принимает платежи

### юзернеймы
- карточка юзернеймов в профиле: основной и дополнительные ("также @…")
- коллекционные (NFT) юзернеймы помечены отдельной меткой
- по нажатию открываются официальные данные Telegram и Fragment: владелец, дата покупки, цена, ссылка на Fragment
- если официальных данных нет, ничего не придумывается

### анонимный номер
- выбор отображения своего номера: реальный номер, замаскированный номер или FlashGram ID
- замаскированный номер оставляет код страны и две последние цифры
- меняется только то, что показывает FlashGram на этом устройстве; номер Telegram-аккаунта и настройки приватности не меняются

### сервер и безопасность
- защита от флуда и DDoS: лимиты запросов по IP и по аккаунту на всех публичных функциях сервера
- ограничение частоты заявок на верификацию
- клиент сам делает паузу, если сервер ответил "слишком много запросов"
- статус заявок и бейджи меняются только на сервере; клиент не может выдать себе бейдж или одобрить заявку
- все таблицы закрыты для прямого доступа, работа идёт только через проверяемые функции

### дизайн
- единый тёмный премиум-стиль экранов FlashGram: скруглённые карточки, градиенты, аккуратная типографика
- плавные анимации наведения и нажатия на кнопках и карточках
- общий набор компонентов для всех новых экранов FlashGram

## исправлено
- почта: больше не обязательна, окно "регистрация в FlashGram" не выскакивает при запуске; FlashGram ID, баланс, подарки и верификация работают без неё; в профиле у почты стоит "необязательно"
- код из письма: при повторном запросе сразу показывается поле для ввода вместо "слишком много попыток"; лимит на письма больше не блокирует остальные функции FlashGram на минуту
- письма с кодом: шаблон содержит только код без ссылок, код стал 6-значным
- вёрстка: текст не наезжает в карточке плана, витрине NFT и выборе номера; окно верификации не прыгает по высоте при переключении вкладок; под короткими страницами нет светлого фона
- бейджи: "FlashGram Verified" больше не выдаётся локально, только сервером
- рулетка: если на сервере временно нет NFT-призов, показывается "NFT-призы временно недоступны", FG не списываются; в рулетке только NFT-подарки, победителя выбирает сервер
- по мелочи: заголовок витрины NFT не обрезается, метка "FlashGram" не наезжает на заголовки, короче строки требований
- и ещё много мелких изменений, но уже лень перечислять

## установка
1. скачайте FlashGram-Setup-1.0.3.exe
2. запустите установщик и следуйте шагам
3. войдите в Telegram как обычно

портативная версия: распакуйте FlashGram-Portable-1.0.3.zip и запустите FlashGram.exe.
проверить файлы можно по SHA256SUMS.txt.
